# 3. Primeros pasos

## Abrir el plugin

Haz clic en el ícono **Agenda** en la barra lateral izquierda (ribbon). Esto abre una nueva pestaña con la interfaz principal del plugin, donde puedes cambiar entre las distintas familias de vistas usando las pestañas del encabezado.

Por defecto, todas las familias de vistas están visibles. Puedes ocultar las que no uses desde **Configuración → Agenda Tasks → Visibilidad de pestañas** (ver [9. Configuración](08-configuration.md)).

## Las familias de vistas principales

| Pestaña | Para qué sirve |
|---|---|
| **Vista general** | Un panel con métricas clave, tareas próximas/vencidas y widgets de progreso |
| **Lista** | Una lista de tareas detallada y filtrable |
| **Tabla** | Una cuadrícula de tareas estilo hoja de cálculo, con columnas ordenables |
| **Calendario** | Seis diseños de calendario para ver las tareas en una línea de tiempo |
| **Hábitos** | El módulo de Seguimiento de hábitos (separado de las tareas — ver [6. Seguimiento de hábitos](05-habit-tracker.md)) |

Tus tareas se completan automáticamente: el plugin analiza tu bóveda en busca de líneas con casilla (`- [ ] ...`) y procesa sus metadatos — no hay nada que importar ni configurar antes de ver tus tareas existentes.

## Crear tu primera tarea

Puedes crear una tarea desde cualquier vista:

- **Paleta de comandos**: presiona `Ctrl+P` (o `Cmd+P` en macOS) y busca un comando de "crear tarea" de Agenda Tasks.
- **Vistas de calendario**: haz doble clic en una celda de día vacía, una franja horaria, o la sección "Todo el día" para abrir el modal de creación de tareas prellenado con esa fecha (y hora, cuando corresponda).
- **Barra de herramientas de Lista/Tabla**: usa el botón de crear en la barra de herramientas de la vista.

El modal de creación se abre con un conjunto básico de campos (título, fecha programada, prioridad) y una sección opcional "Más campos" para todo lo demás — consulta [7. Formato de tareas y metadatos](06-task-format.md) para la referencia completa de campos.

## Editar una tarea existente

Haz clic en una tarea (en cualquier vista) para abrir el mismo modal, prellenado con sus datos actuales. Un doble clic en cambio abre directamente la nota subyacente, con el cursor en esa línea.

## Acciones comunes de un vistazo

| Acción | Cómo |
|---|---|
| Filtrar tareas | Usa el panel de filtros (vistas Lista/Tabla) |
| Crear una tarea | `Ctrl+P`, el botón de crear, o doble clic en una vista de calendario |
| Editar una tarea | Haz clic en la tarea |
| Abrir la nota detrás de una tarea | Doble clic en la tarea |
| Ordenar tareas | Haz clic en un encabezado de columna (vistas Lista/Tabla) |
